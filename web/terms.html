2. 本ツールについて

  • 本ツールは、インターフェース基板を介してバッテリーパックの情報を読み取り、一部の操作（エラー解除など）を行うためのツールです。
  • 本ツールは株式会社マキタその他のメーカーとは関係がなく、それらのメーカーが承認・提供するものではありません。記載の製品名・型番は各社の商標または登録商標です。

3. バッテリーへの書き込みと安全

  • 「エラー解除」などの書き込み操作は、バッテリー内の記録を書き換えます。バッテリーによっては充電回数などの記録が初期化されること、または正常に動作しなくなることがあります。書き込んだ内容を元に戻すことはできません。
  • メーカー保証やサポートの対象外となる場合があります。

ロックやエラーは、メーカーが安全のために設けた保護機能である場合があります。セル電圧の異常、膨張・変形・液漏れ・異臭・発熱、落下や水濡れの履歴があるバッテリーについては、エラー解除や再使用・充電をしないでください。発火・破裂のおそれがあります。

書き込み操作は、利用者ご自身の判断と責任において行ってください。

4. 禁止事項

  • 法令または公序良俗に反する利用
  • 状態が異常または不明なバッテリーを、エラー解除などにより正常品と誤認させて販売・譲渡する目的での利用
  • 本ツールまたは当方のサーバーへの不正アクセス、過度な負荷をかける行為

6. 読み取りデータの送信とプライバシー

  • 「この読み取り結果を PowerDiag に送信する」が有効な場合、読み取りのたびに次の情報を当方のサーバーへ送信します：型番、ROM ID、製造日、充電回数、ロック・状態の情報、容量、パック電圧・セル電圧・温度、バッテリーのメッセージデータ、インターフェース基板のファームウェアバージョン、本ツールのバージョン、表示言語、送信日時。あわせて、送信元の IP アドレスを記録します。
  • 氏名やメールアドレスなど、利用者を直接特定する情報は送信しません。
  • 利用目的：バッテリーの状態傾向の把握、本ツールおよび基板の互換性・品質の改善、不具合や不正利用の調査。IP アドレスは、おおよその国・地域の把握と不正利用の調査に使います。

  • 保存：データは日本国内のサーバーに保存し、上記の目的に必要な期間保管します。
  • 送信の停止：チェックを外すと送信しません（設定はこのブラウザに保存されます）。デモ表示のデータは送信しません。
  • 削除の依頼：送信済みデータの削除を希望される場合は、ROM ID とおおよその送信日時を添えて下記までご連絡ください。
